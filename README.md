# Roundabout for Mac

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A lightweight macOS utility for customizing window corner radius with a simple slider interface.

## Features

- **Adjust corner roundness** from 1 to 24 pixels
- **Era presets** matching classic macOS designs:
  - System 1 – Mac OS 9 (radius: 1)
  - Mac OS X 10.0 – macOS 10.15 (radius: 4)
  - macOS 11 – macOS 15 (radius: 10)
- **Two modes**: Run as a Dock app or menu bar utility
- **Auto-quit** option to close after applying changes
- Real-time preview with instant feedback

## Installation

1. Download the latest release from the Releases page
2. Open the .dmg file and drag Roundabout to your Applications folder
3. Launch the app

## Usage

1. Use the slider to select your desired corner radius (1-24)
2. Or click a preset button for a specific macOS era look
3. Click **Apply Changes**
4. Close and reopen apps for changes to take full effect

### Menu Bar Mode

- Toggle "Menu Bar Only Mode" in Settings to hide the Dock icon
- Access the app from your menu bar
- Switch back to Dock mode at any time

## Requirements

- macOS 12.0+ (Monterey) or later
- Menu Bar Only Mode requires macOS 13.0+ (Ventura)
